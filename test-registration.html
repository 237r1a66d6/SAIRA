⚠️ Common Issues & Solutions

  • Button does nothing: Check browser Console (F12) for JavaScript errors
  • API object undefined: Make sure api-config.js is uploaded and loaded
  • Network errors: Check db_connect.php has correct Hostinger credentials
  • 404 on API: Verify /api/ folder and PHP files are uploaded
  • Page refreshes: Form had action="register_handler.php" (now fixed)
